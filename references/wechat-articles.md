# 推文（微信公众号）

**W-1 配色方案**
先确定与主视觉相符合的推文专用配色方案，作为全部组件的统一视觉约束。

**W-2 组件清单**
确定本批次需制作的组件列表与装饰图标（icon）列表，**组件数量与 icon 数量须先行询问用户**。常用组件类型：

> 大标题、底色标题、框线标题、左右线标题、双行标题、序号标题｜框线正文、序号正文、首字放大、双列对照、要点清单、行内标注、虚线提示框｜引用块、提示块、金句块、手账条带｜目录栏、推荐阅读栏、关注引导、图片说明条｜分割线、留白块

装饰 icon 示例：星星、月亮、月饼、书本、笔、爱心等，须符合用户主题要求。

**W-3 方案审阅与试做**
配色方案 + 组件清单提交用户审阅；通过后**先生成部分组件与内容的试做版**。输出形态：**HTML/CSS 组件代码 + 本地预览页**（交付时直接**打开本地预览页**供用户查看）。

公众号编辑器会剥离 `<style>`、`class` 与外部 CSS，且不支持 `flex`、`grid`、`position`。因此组件必须写成**可直接粘进公众号编辑器的内联样式**：

- 全部样式写在元素 `style` 属性内，不使用 `<style>`、class、选择器与 CSS 变量
- 结构以 `section` / `table` 为主，多列排布用 `table` 兜底，不依赖 flex 或 grid
- 字号、行高、颜色、间距逐元素写死，不依赖继承
- 试做版须完成一次「复制 → 粘进公众号编辑器 → 预览」的验证，确认样式未丢失后再继续

**W-4 全量生成**
试做版经用户审核通过后，再全量生成其余组件。

**W-5 示例推文（可选）**
全部组件产出后，主动询问用户是否需要制作示例推文。若需要：主题须结合用户提供的信息与主视觉调性，文案由 AI 撰写，排版**必须调用本批已产出的组件**实现，不得引入新样式。
