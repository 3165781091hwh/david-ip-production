# 主视觉体系与角色资产

| 步骤           | 输入            | 产出       | 要点                            |
| ------------ | ------------- | -------- | ----------------------------- |
| **P-1 概念确立** | 用户需求          | 现实概念特征清单 | 问询用户是否进行网络检索，以准确把握该现实概念       |
| **P-2 人设图**  | P-1 特征清单      | 白底人设图    | **规格固定：白底、正面、全身、单人**；产出后须审核定稿 |
| **P-3 三视图**  | P-2 人设图（唯一参考） | 正/侧/背三视图 | 形象细节全部锁定，作为后续所有产线的形象锚点        |
| **P-4 主视觉图** | P-3 三视图（唯一参考） | 主视觉成品图   |                               |

> P-2 → P-3 → P-4 为严格串行，不得并行。
