# 执行细节（跨板块）

**X-1 后期叠字**

1. **生成阶段不在图内写字**：提示词里只预留配字区（纯色或留白、与主体明确分区），并写明「该区域不出现任何文字、类文字笔画或伪字形」。
2. **叠字阶段**：字体取 `config.local.md` 的三个语义槽位——`FONT_STICKER`（表情配字）、`FONT_POSTER`（海报标题与卖点）、`FONT_BODY`（推文正文）。槽位未登记时，先跑 `python scripts/font_probe.py` 出样张，请用户按样张编号挑，再 `python scripts/font_probe.py --pick 3,7,12` 写入；不得用系统默认字体蒙混。
3. **同批锁死**：字号、描边、行距、边距四个参数在一批内不得变动；竖排配字自右向左分列。
4. **交付**：成品 PNG + 同名 `.json` 文案表（文案、字体槽位、字号比例、颜色、锚点）。改字只重跑脚本，不重跑图。
5. **尺寸归一到叠字之前**：参考图生图的输出尺寸跟随参考图，先统一裁切／缩放到方案尺寸（表情包 720×720），再叠字，保证同批字号与边距一致。

参数基线（720×720 表情包）：字号 0.085–0.10H，描边 0.004–0.006H，边距 0.06，字色与描边取主视觉配色。海报按画幅等比放大，并保证配字区不压主体。

例：`python scripts/overlay_text.py --base in.png --text "就是这个" --font "C:/Windows/Fonts/msyhbd.ttc" --size 0.09 --color "#2F80ED" --stroke 0.005 --anchor right-center --out out.png`

**X-2 标识参考图**

1. **启用条件**：IP 绑定具体产品（包装、器具、实物）或已有固定 logo／商标；无标识则整节跳过。
2. **传递顺序**：先三视图，再标识图；提示词写明「第 N 张为标识／产品外观的唯一基准，不得改形、改色、拉伸、加描边、重绘光影」。
3. **冲突裁决**：角色形态听三视图；标识与产品外观听标识图。
4. **首选后期合成**：logo 能叠就不用模型画（`overlay_text.py --logo … --logo-anchor … --logo-size …`）。只有标识必须与画面物理融合（印在衣物、包装、贴纸、实物表面）时才交给模型。
5. **校验**：逐张核对标识的比例、颜色、笔画走向与字形，变形或错字即判废重出。
